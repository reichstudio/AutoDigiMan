# 数字人应用场景分镜与提示词规则

规划与写提示词之前，先读所选用途对应的场景条目。场景规则提供该类视频的分镜结构、景别习惯、节奏、表演与图文默认值；用户输入与官方 H3 框架（`h3-prompt-writing` 六段结构与标签规则）优先于场景默认值。

## 通用原则（全部场景适用）

- **正式严肃场景固定机位优先**：新闻播报（含油管/YouTube 新闻）、政企讲解、教育网课，以及采用正式严肃基调的金融保险、企业内训、医疗科普、法律合规等讲解，默认全程 `Static Shot`，锁定机位、角度、焦段与构图。禁止默认添加缓推、推拉、摇移、环绕、跟拍、变焦或手持漂移；用户明确要求时才按最小必要幅度使用。主讲可跨单元保持同一构图，仅在内容确需资料/课件/操作特写时少量切换固定机位。此规则优先于本页的景别渐进、切镜变化和其他通用运镜建议；自然表情、手势与演示动作仍保留。

- **景别渐进**：同一叙事段落内按 远景/全景 → 中景 → 近景/特写 渐进组合，段落切换处允许大跨度景别跳变（硬切重开）。
- **结构模板是骨架**：实际段落划分、单元边界与时长以锁定脚本和时间轴为准；结构模板决定"每一类内容用什么景别与运镜承载"。
- **B-roll 映射**：条目中的"插入/broll"对应清单 `mode: "broll"`，画外音延续；出镜讲解对应 `speak` / `demo`。
- **图文层**：条目中的字幕、要点卡、角标均为"用户启用时"按官方 on-screen text 规则添加（画面内可见文字用英文双引号逐字保留）；用户未启用时画面保持干净。
- **页标题后缀**：作为 `page_titles.h3` / `page_titles.list` 的默认值，用户可另选。
- **运镜词汇**：使用官方运镜表（Push In/Pull Out、Pan、Truck、Tilt、Pedestal、Arc Shot、Tracking Shot、Static Shot、POV、Zoom、Shake、Roll）+ 幅度 + 速度。

结构来源：带货类采用"黄金3秒钩子 → 痛点具象 → FAB 卖点（特性-优势-利益）→ 催单"成熟公式；知识讲解类采用 SCQA（情境-冲突-疑问-答案）与总分总/PREP；企业类采用篇章式（片头造势 → 篇章主体 → 升华收尾）。

## 语速档位与单元节奏（全场景适用）

- **语速档位**：分镜时间轴按场景语速档位推导，用户实测语速优先于档位默认值：
  - **快档 240–260 字/分钟**：电商带货（默认基准）、商场导购、3C数码测评、新闻播报；
  - **中档 200–240 字/分钟**：企业客服、文旅导游、教育网课、房产/汽车讲解、招聘宣讲、活动主持；
  - **稳档 160–200 字/分钟**：政企讲解、金融保险、法律合规宣讲、医疗健康科普、企业内训、线上发布会、公益宣传；
  - **实测档**：真人IP复刻（语速取自参考视频分析）。
- **单元长度与切镜**：全部场景的每个 H3 单元目标 **10–15 秒、尽量贴近 15 秒上限**，实际时长由内容决定；每个单元默认单镜头连续完成，景别、机位或场景变化用单元内 `[Shot N] At MM:SS.mmm` 内部切镜呈现，台词跨切按官方 `<scenetrans>` 规则声明声音延续。快剪指切镜密度而非单元长度：电商带货在启动确认时由用户选择节奏风格——正常切镜（每单元 1–2 个内部切镜）或快剪（约 15 秒单元内 2–3 秒一次高密度切镜）。
- **单元内容容量**：按「语速档 × 单元时长」折算口播字数并聚合脚本句子——稳档 15 秒约 40–50 字、中档约 50–60 字、快档约 60–65 字；单元内同步完成人物动作剧情与所讲内容，起止状态覆盖完整语段。

### 01 电商带货（商品讲解、直播带货切片）

- **基调与结构**：转化导向、节奏最快。黄金3秒钩子（痛点具象化/悬念缺口/情绪钩子）→ 痛点场景 → FAB 卖点逐条演示 → 信任背书 → 催单收尾（价格锚点、限时限量、行动指令）。
- **讲者设定**：亲和有感染力的主播形象；表情热情、语速偏快；产品常在手上或近身。
- **场景与用光**：直播间/样品间/居家使用场景；高亮度主光 + 产品重点光（产品区比面部亮约半档），背景陈列货架或真实使用环境。
- **分镜序列模板**：①钩子——讲者与产品同框中近景，Static Shot 起手后快速 Push In 强化表情与产品同现；②痛点——中景，讲者比划问题场景，可切使用痛点空镜（broll）；③卖点演示——手部操作产品特写与讲者中景在单元内切镜交替，一至多条卖点装入同一单元，手指指向具体卖点部位；④背书——中近景，屏幕/证书以 broll 或单元内切镜插入；⑤催单——近景讲者与产品同框，手势指向价格信息位，收束动作定格。
- **节奏**：语速快档 240–260 字/分钟；单元长度与其他场景一致，10–15 秒贴近上限。启动确认时由用户选择节奏风格：快剪——约 15 秒单元内每 2–3 秒一次内部切镜，卖点之间在单元内切镜转换，痛点与催单段切镜更密，背书段稍缓；正常切镜——每单元 1–2 个内部切镜。
- **提示词要点**：`detailed_description` 写明手与产品的接触方式（握、翻、按、举）、手指指向的具体部位、标签/Logo 朝向镜头的时刻；broll 单元写产品旋转展示、材质微距与使用效果前后对比。
- **图文层（用户启用时）**：卖点关键词卡、价格/优惠角标、倒计时条。
- **页标题后缀**：电商带货版。

### 02 政企讲解（政策解读、政务宣传、党建宣传）

- **基调与结构**：庄重权威。总分总或 SCQA（政策背景 → 变化点 → 核心问答 → 落实要求）。
- **讲者设定**：正装、稳重亲和；语速平稳，手势幅度小而明确（掌心向上引导、要点处手指示意）。
- **场景与用光**：会议室/政务大厅/办公背景，机构标识元素；大面积柔光主光 + 侧轮廓分离，色调沉稳。
- **分镜序列模板**：①开场——对称中景 Static Shot；②要点段落——保持同一固定半身构图，重点句通过语气和小幅手势强调；③数据/文件——有必要时硬切固定图表或文件特写；④落实/结尾——回到同一固定主机位，自然收束。
- **节奏**：语速稳档 160–200 字/分钟（慢而稳）；10–15 秒单元尽量贴近 15 秒上限，段内单镜头连续，景别变化用内部切镜；段落边界处硬切。
- **提示词要点**：坐姿/站姿端正；文件翻阅或指示牌交互；讲者视线在侧屏与镜头之间的联动（先看屏引出图文，再回镜头确认）。
- **图文层（用户启用时）**：政策要点条、日期文号角标。
- **页标题后缀**：政企讲解版。

### 03 新闻播报（新闻资讯、天气预报）

- **基调与结构**：客观正式。导语 → 主体（5W 要素）→ 结语；口播贯穿全片。
- **讲者设定**：正装主播，端正坐姿，目视镜头，标准语速，手势克制（接近零）。
- **场景与用光**：新闻演播室主播台 + 背景大屏；冷白均衡布光，面部均匀，背景屏亮度低于面部约一档。
- **分镜序列模板**：①开场——中近景 Static Shot；②条目——保持同一固定主播构图，重点条目不推近或变焦；③配片——内容需要时硬切固定新闻资料、地图或图表画面，讲者画外音延续（官方 voiceover 规则：`says in an off-screen voiceover` + 画面人物 lips remain completely closed）；④结语——回到同一固定主播主机位。油管新闻播报同样执行。
- **节奏**：语速快档 240–260 字/分钟（播报腔稳而快）；10–15 秒单元贴近上限，机位变化少，条目切换用单元内内部切镜或段落边界硬切。
- **提示词要点**：低头看稿再抬眼的节奏；broll 前后的视线与语流衔接（`<scenetrans>`）。
- **图文层（用户启用时）**：标题条、日期角标、天气图位。
- **页标题后缀**：新闻播报版。

### 04 企业客服（智能客服、售后指引）

- **基调与结构**：亲切清晰、步骤化。问题引入 → 分步操作 → 结果确认。
- **讲者设定**：职业装、微笑亲和；手势以指引为主（掌示侧屏、数字手势报步骤）。
- **场景与用光**：简洁办公/虚拟纯色背景；均匀明亮，面部无重影。
- **分镜序列模板**：①问题引入——中近景；②步骤——每个步骤一个单元：讲者中景（数字手势）+ 侧屏界面 broll 或人屏同框；③结果确认——近景微笑收束。
- **节奏**：语速中档 200–240 字/分钟；10–15 秒单元贴近上限，多个步骤合并进同一单元，步骤之间用内部切镜推进，编号随切镜更新。
- **提示词要点**：手指方向与屏幕元素位置一致；界面出现时刻与讲者描述语句对齐；常见问题卡片交互。
- **图文层（用户启用时）**：步骤编号 1/2/3、提示条。
- **页标题后缀**：企业客服版。

### 05 文旅导游（景区讲解、博物馆导览）

- **基调与结构**：环境代入。迎客 → 行进讲解 → 景点细读 → 总结邀约。
- **讲者设定**：导游装/休闲，活力亲和；走动讲解，手势指向景观，视线在镜头与景物间切换。
- **场景与用光**：实景景区/博物馆；自然光为主 + 轻量人物补光，画面纵深层次丰富。
- **分镜序列模板**：①迎客——全景人景同框，Tracking Shot 走动跟拍；②行进——中景跟拍讲解，路标/建筑/展柜交互；③景点细读——讲者手势引导 → broll 空镜（全景氛围 + 细节特写）→ 回讲者近景总结；④邀约——近景收束。
- **节奏**：语速中档 200–240 字/分钟；10–15 秒单元贴近上限，走动段单镜头连续跟拍；景点空镜 broll 4–6 秒；景点切换处硬切。
- **提示词要点**：行走路线与镜头跟随关系（转弯预判、Trucking 方向）；手势指向与实际景观方位一致；门票/展品/护栏等道具交互。
- **图文层（用户启用时）**：景点名称条、路线箭头。
- **页标题后缀**：文旅导游版。

### 06 商场导购（门店促销、导购介绍）

- **基调与结构**：促销氛围。迎宾 → 动线导览 → 商品推介 → 优惠收束。
- **讲者设定**：品牌制服/工装，热情得体；引路手势（五指并拢指向）、商品双手展示。
- **场景与用光**：门店/专柜实拍；店内照明 + 人物补光，橱窗与灯箱入镜作实用光源。
- **分镜序列模板**：①迎宾——中景，门店招牌入画；②动线——中景走动引导（Tracking Shot），货架/陈列交互；③商品——讲者与商品同框近景 + 商品特写 broll；④优惠——近景 + 促销信息位。
- **节奏**：语速快档 240–260 字/分钟；10–15 秒单元贴近上限，动线段连续跟拍，商品推介与优惠收束用内部切镜衔接。
- **提示词要点**：走位与通道方向；商品取放动作（从货架取下、转向镜头）；价签朝向镜头的时刻。
- **图文层（用户启用时）**：促销价签、会员信息条。
- **页标题后缀**：商场导购版。

### 07 教育网课（在线课程、知识付费）

- **基调与结构**：讲解清晰。总分总 + 三步循环（提问 → 设概念 → 解释概念）。
- **讲者设定**：教师形象，亲和耐心；手势辅助比划（数量、比例、方向），指示板书/课件。
- **场景与用光**：书房/教室/课件虚拟背景；均匀柔光，板书区或侧屏与人物同亮。
- **分镜序列模板**：①开场提问——固定中近景 Static Shot；②概念讲解——同一固定半身构图内指向课件/板书；③例题演示——确需看清细节时硬切固定手部书写特写或固定课件画面；④总结——回到同一固定主机位收束。板书、指示和手部动作不触发跟拍、摇移或变焦。
- **节奏**：语速中档 200–240 字/分钟；10–15 秒单元贴近上限，知识点边界为单元边界；书写/课件切换用内部切镜。
- **提示词要点**：书写/点击动作与讲解同步；公式与图示的指向顺序；低头-抬头节奏。
- **图文层（用户启用时）**：知识点卡、公式字幕、进度条。
- **页标题后缀**：教育网课版。

### 08 金融保险（理财讲解、保险条款解读）

- **基调与结构**：专业可信。SCQA（市场情境 → 变化/风险 → 疑问 → 方案）。
- **讲者设定**：正装，沉稳自信；手势幅度小而精确（数据手指示意、掌心展开呈现方案）。
- **场景与用光**：办公室/金融数据屏背景；冷色专业布光，侧轮廓分离，背景克制虚化。
- **分镜序列模板**：①引入——中景；②数据陈述——近景 + 图表 broll；③方案讲解——半身 + 方案/条款卡交互；④提醒收尾——近景，风险提示语气收束。
- **节奏**：语速稳档 160–200 字/分钟；10–15 秒单元贴近上限；图表引用用内部切镜，数据密集段在单元内以局部时间线呈现。
- **提示词要点**：图表出现时刻与讲者引用语句对齐；文件翻阅动作；屏幕数字的朝向与可读性。
- **图文层（用户启用时）**：数据角标、风险提示条。
- **页标题后缀**：金融保险版。

### 09 真人IP复刻（个人分身、老板IP、达人复刻）

- **基调与结构**：以参考视频分析结论为准（见 [digital-human-workflow.md](digital-human-workflow.md)「真人IP复刻的参考视频分析」）；整体结构跟随被复刻者的内容形态。
- **讲者设定**：主体定义完整承载外观/体态/着装特征；表演描述承载动作习惯、表情、语速与标志性动作。
- **场景与用光**：沿用被复刻者的常见场景与光感。
- **分镜序列模板**：沿用其常用景别与开场/收尾习惯；标志性动作安排在开头 3 秒与段落转折处；段落结构按其内容类型套用对应场景条目（带货/知识/观点）。
- **节奏**：语速取参考视频实测；单元时长随其内容节奏，目标 10–15 秒贴近上限，内部切镜沿用其剪辑习惯。
- **提示词要点**：参考视频按官方规则引用——可见内容（人物、动作）在 `<Subject N>` 定义内引用视频来源，镜头运动或节奏结构用 `<Video N>` 标注，`retention_analysis` 按实际保留程度选标记；表演描述的具体程度对齐分析清单五类特征。
- **图文层（用户启用时）**：随其内容形态（IP 名条、口号字幕）。
- **页标题后缀**：真人IP复刻版。

### 10 线上发布会（产品发布、年会主持）

- **基调与结构**：舞台仪式感。开场造势 → 主题宣讲 → 产品揭幕 → 参数亮点 → 致谢。
- **讲者设定**：正式着装/深色礼服，台风大气；揭幕手势（手臂展开指向大屏或产品台）。
- **场景与用光**：发布会舞台；追光 + 大屏作为动机光源，逆光轮廓分离，观众席保持暗部。
- **分镜序列模板**：①开场——舞台全景 + 讲者入场（Tracking Shot），Arc Shot 环绕亮相；②宣讲——半身，讲者指向大屏、屏幕内容随之切换；③揭幕——中景 → broll 产品特写/旋转展示，追光跟随产品；④亮点——参数卡 broll 与讲者近景交替；⑤致谢——全景收束。
- **节奏**：语速稳档 160–200 字/分钟；10–15 秒单元贴近上限；揭幕段在单元内以内部切镜与局部时间线展开，给足 6–10 秒动作时间。
- **提示词要点**：大屏内容与讲者话术同步切换；追光与走位绑定；掌声氛围写入 `overall_soundscape`。
- **图文层（用户启用时）**：参数卡、Logo 水印、倒计时。
- **页标题后缀**：线上发布会版。

### 11 企业内训（员工培训、产品培训、合规培训）

- **基调与结构**：实操导向。目标 → 流程分步 → 常见错误 → 考核要点。
- **讲者设定**：职业装，耐心细致；屏幕操作与实物演示结合。
- **场景与用光**：会议室/工位/操作台；均匀办公光 + 操作区重点光。
- **分镜序列模板**：①目标说明——中景；②分步操作——过肩（over-the-shoulder）或 POV 屏幕操作与讲者中景交替；③错误示范——正确/错误先后对比呈现；④要点收束——中景 + 考核要点卡。
- **节奏**：语速稳档 160–200 字/分钟；10–15 秒单元贴近上限，多个步骤合并进单元，步骤之间内部切镜。
- **提示词要点**：鼠标/手指与屏幕元素的对应；实物操作的手部步骤分解；错误示范与正确操作的明确差异点。
- **图文层（用户启用时）**：步骤编号、注意事项标签。
