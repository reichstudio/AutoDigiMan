# Free 版可复刻视频生产流程

1. 收集主音频或用户给出的时间提示、锁定歌词/台词、现有角色/场景/道具/载具参考图、视觉方向、画幅和可见表演比例。确认项目已有参考图已覆盖所需画面。
2. 以用户提供的逐句时间轴、音频内可核对的句首句尾或人工确认的提示点设计镜头。没有可靠时间证据时，将相应时长标为临时估算，不宣称音频锁定。
3. 查看每张已有图片，建立稳定的全局 `P#` 参考图登记表。Free 版只登记用户提供的图片，不创作或补齐缺失资产，也不写图片生成提示词。
4. 规划覆盖完整音频或脚本的镜头：每条歌词/台词完整落在一个镜头内；每个镜头说明开场状态、主事件、连续或硬切关系、用光、运镜和终帧。
5. 每条 H3 单元选择不超过九张已有图，并按上传顺序换算局部 `<Picture N>`。在 `subject_definitions` 中把每张实际上传图与其全局 `P#` 联系起来。
6. 编写中英文 H3 提示词：质感与用光 → 构图与主动态 → 完整连续的演唱/口播/动作/运镜 → 明确终帧。需要口型时，只写该镜头内完整的锁定歌词或台词。
7. 将数据填入 `project-manifest.json`，生成三页：参考图片清单、双语 H3 提示词页、全中文分镜列表。项目交付铁律：不生成 Markdown 分镜、提示词、资产清单、说明或审核文件；所有用户可见内容进入这三张 HTML 页面。
8. 最后审核：时间、台词/歌词、`P#`、本地 `<Picture N>`、九图上限、连续性、用光、提示词字段、脚本解析，以及页面加载后的筛选、复制、跳转与回顶部交互。
